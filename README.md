# Excel-PKL-Teams-Analysis

## Project Overview
An Interactive Dynamic Pro Kabaddi League Teams Stats dashboard Created using Microsoft Excel to analyze every teams played in Pro Kabaddi League based on their past and current performances in different seasons based on different criteria.

## Tools Used
- Microsoft Excel
- Pivot Tables 
- Pivot Charts
- Slicers
- Advanced Excel Formulas
- Data Cleaning

## Dashboard Features
- Overall Total Analysis
- Seasons Based Analysis
- Teams Stats (Wins/Loss)
- Titles Won By Teams
- Super Raids & Super Tackles By Teams
